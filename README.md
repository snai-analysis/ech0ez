EC$H_0$EZ: Early Cosmological ($H_0$) Estimation from ZTF SN Ia DR2
===================================================================

[![arXiv:2610.36051](https://img.shields.io/badge/arXiv-2610.36051-b31b1b?logo=arxiv&logoColor=red)](https://arxiv.org/abs/2610.36051)

This repository contains:
- `data`: 
  - `PantheonPlus`: external (SH0ES) inputs from https://github.com/PantheonPlusSH0ES/DataRelease
  - `ztfdr2`: external (ZTF) inputs from https://ztfcosmo.in2p3.fr
  - `pplus-cdd_*.csv`: Pantheon+SH0ES calibrators (de-duplicated) from different fits (`nom` = "nominal", as released); generated by `ech0ez-0-fit.ipynb`
  - `ztfdr2-vlqh_*.csv`: ZTF SN Ia DR2 (volume-limited, high-quality) from different fits (`nom` = "nominal", as released); generated by `ech0ez-0-fit.ipynb`
  - `pplus-cdd-hosts.npz`: distance moduli and covariance of calibrator hosts, derived from SH0ES; generated by `ech0ez-0-fit.ipynb`
  - `ztfdr2-vlhq_nom-manticore.npz`: cosmological redshifts and covariance for ZTF, derived from Manticore; generated by `manticore.ipynb`
  - `pkg/*`: packaged data (calibrators+HF, host distance moduli and host indices, HF redshifts and covariance); generated by `ech0ez-1-pkg.ipynb`
- `res`ults
  - `stats.csv`: a summary table with posterior mean and st. dev., effective sample size, and $\hat{R}$ statistic per global parameter per data+model variant
- code:
  - `libech0ez`: a library of "science" code:
    - `lcfit.py`: utilities for fitting light curves
    - `vpec.py`: utilities for correcting peculiar velocities
    - `cosmax.py`: (approximate) cosmological distance calculations in jax
    - `model_numpyro.py`: the forward model, in numpyro
    - `helper.py`: helper for loading and analysing data 
  - `ech0ez-0-fit.ipynb`: ingests raw external inputs and generates the "intermediate" data tables; also re-fits using different SALT models and Milky Way dust laws
  - `ech0ez-1-pkg.ipynb`: packages data so it's ready for HMC
  - `ech0ez-2-hmc-batch.py`: runs HMC on packaged data (all given file names `PKG ...`) and saves the result in `res/PKG/VARIANT.pickle`. The `-b` switch selects the baseline model variant; otherwise, all model configurations are run in parallel.
  - `ech0ez-paper-*.ipynb`: produce the (data required for compiling, in LaTeX) the paper's figures

Code requirements can be found in `requirements.txt` and installed with `pip install -r`.
